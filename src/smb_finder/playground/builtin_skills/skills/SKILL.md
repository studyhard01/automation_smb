# Skills Help

When invoked with `/skills`, list every installed `SKILL.md` with its id, description, and source.

- Explain that selected skills are injected into the agent system prompt for the current chat request.
- Point the user to the Skills button below the Chatbot Playground composer for selection and management.
- Do not call an LLM or another tool just to produce the list.
