# Tools Help

When invoked with `/tools`, list every currently registered Playground tool grouped by category.

- Show the tool id, display name, description, and whether it is currently enabled.
- Explain that only tools selected in the left panel may be called during normal chat.
- Do not call an LLM or another tool just to produce the list.
